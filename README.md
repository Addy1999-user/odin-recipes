# Tap Empire

Tap Empire is a mobile-first idle clicker with a polished progression loop:
**tap -> earn -> upgrade -> automate -> prestige -> repeat**.

## Features
- Tap earning, auto-income, upgrade shop
- Offline income while away
- Daily reward and quest rewards
- Prestige reset with permanent multiplier
- Reward chest progression (deterministic, non-gambling)
- Save/load to localStorage
- Settings toggle (sound)
- Monetization integration hooks (rewarded ads + cosmetic IAP stubs)

## Run locally
```bash
npm install
npm run dev
```

## Build and test
```bash
npm run test
npm run build
```

## Product notes
- No gambling mechanics or dark patterns.
- Reward chest is guaranteed and progress-based.
- Ad and IAP hooks are placeholders for safe future integration.
